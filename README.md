# Yandex Disk API Autotests

Проект автотестов для [REST API Яндекс.Диска](https://yandex.ru/dev/disk/rest/).

## Стек

| Инструмент | Версия | Назначение |
|---|--------|---|
| Java | 25     | Язык |
| JUnit 5 | 5.10.2 | Тест-фреймворк |
| REST Assured | 5.5.6  | HTTP-клиент для тестов |
| Maven | 3.9+   | Сборка |
| dotenv-java | 3.2.0  | Загрузка токена из `.env` |

## Покрытие тестами

| Метод | Endpoint | Тестируемые сценарии |
|---|---|---|
| GET | `/v1/disk` | 200, наличие полей, 401 |
| GET | `/v1/disk/resources` | 200 для корня, 404 для несуществующего |
| PUT | `/v1/disk/resources` | 201, наличие href, 409 дубликат, 400 пустой путь |
| POST | `/v1/disk/resources/copy` | 201, наличие href, 409 дубликат, 404 несуществующий |
| DELETE | `/v1/disk/resources` | 204, 404 несуществующий, проверка удаления через GET, 400 пустой путь |

## Запуск

### 1. Получить OAuth-токен

Зарегистрировать приложение на [Яндекс OAuth](https://oauth.yandex.ru/) и получить токен через [полигон](https://yandex.ru/dev/disk/poligon/).

### 2. Создать `.env` файл

```bash
cp .env .env
```

Вставить токен в `.env`:

```
YANDEX_TOKEN=ваш_токен_здесь
```

### 3. Запустить тесты

```bash
mvn test
```
